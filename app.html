Behaviour

What it does at each step.

Everything below runs on the phone. There is no account to make, no server to trust and no upload to forget about.

Record

Six seconds, one channel, 20 Hz to 2 kHz. The waveform, the wall estimate and the quality score are stored as one object, so a reading is never separated from the conditions that produced it.

Correct

Divides the murmur band by the wall it just estimated. The corrected trace and the raw trace are both kept, so the correction can always be audited against what was heard.

Keep

Exports WAV and JSON together. A colleague hears the same sound rather than a description of it, and the file opens without this app.

Refuse

Under 45 per cent contact there is no reading, only a prompt to try again. A false reassurance is the failure that hurts a patient, so the default is to say nothing.

Under the interface

What runs where.

Capture

Web Audio on the demo; the I2S front end on the device. 48 kHz, 24-bit.

Analysis

FFT 4096, three bands, one quality score.

Gate

Contact under 45 per cent returns nothing.

Output

WAV and JSON, stored on the device.

Upload

None. There is no server in this path.

The demo page is single channel, so it shows the correction and the gate but not the differential front end. The firmware build adds the second microphone.
